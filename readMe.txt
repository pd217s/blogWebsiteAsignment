# how to use
to use this website open the index in your web browser of choice. To navigate the website hit the new post button to make a new post or click on a premade one to view it.

# My problems making this
## hard parts
I could not figure out how to use tiny.cloud for the life of me. So instead I went the rout of making myself a simpler version. Because of that I also misunderstood the directions and thought I was supposed to use .json files. the problem with that is there are very few good guides on .json. Due to that I found a work around using session storage. I on retrospect I should have just done that either way. My second biggest issue was how to make an unlimited amount of posts. I solded this by having a simple name in the session storage and having a number counter that never goes down.

## easy parts
deleting data by setting it to null was the easiest solution to all the problems I had.
